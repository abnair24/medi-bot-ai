# Dev + eval dependencies. Tools ONLY — deliberately does NOT `-r requirements.txt`.
#
# WHY: there is a HARD, unavoidable version conflict between two declared pins —
#   - deepeval 4.x        pins click<8.4.0   (overly strict; it works fine with 8.4.2
#                                             as a library — we use its metrics API,
#                                             not its CLI)
#   - huggingface-hub     pins click>=8.4.2  (a REAL hard requirement, pulled by the
#                                             base app via sentence-transformers/docling)
# No single click version satisfies both, so pip's strict resolver REFUSES any solve
# that contains both at once (ResolutionImpossible). deepeval does NOT pull
# huggingface-hub, so the trick is to install them in SEPARATE, ORDERED pip commands:
#
#   pip install -r requirements-dev.txt   # deepeval + tools  -> click<8.4.0
#   pip install -r requirements.txt       # base app (hf-hub) -> bumps click to 8.4.2
#
# The second command emits a warning ("deepeval requires click<8.4.0 ... incompatible")
# but SUCCEEDS, leaving click at 8.4.2 (hf-hub happy) and deepeval fully functional.
# The Dockerfile.backend RUN step encodes this order. NEVER combine the two -r files
# in one pip invocation.
